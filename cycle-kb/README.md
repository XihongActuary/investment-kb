# 四季 · 投资周期地图

把「经济周期」从名词变成可定位、可量化、可执行的坐标系。纯静态站点（HTML + Canvas，无外部依赖，可离线打开）。

## 页面结构

| 文件 | 内容 |
|------|------|
| `index.html` | 总览：四季框架、2026-11 三地不同季的结论、六模块导航 |
| `theory.html` | 七种周期理论：基钦/朱格拉/库兹涅茨/康波/美林时钟/达利欧债务周期/明斯基与金融周期，含实证强度评级与失效场景 |
| `locator.html` | **周期定位器（核心交互）**：七个有量纲参数 → 象限判定 + 五类资产相对得分 + 模型权重 + 动态风险清单；内置 6 个历史情景；模型口径完全公开 |
| `structure.html` | 慢变量：国家生命周期、中国人口（2000–2025 图表）、信贷杠杆、房地产出清、AI 资本开支 |
| `allocation.html` | 持币/债/黄金/股票的当下定位：收益三分解、四季表现矩阵、方向性倾斜 + **证伪条件**、五大风险 |
| `playbook.html` | 投资纪律：收益三因子、风险三种定义、配置 vs 择时（含 91.5% 误读的澄清）、保险资金 ALM 视角、12 条检查清单 |
| `refs.html` | 参考书目、关键论文、一手数据源链接、季度更新流程 |
| `about.html` | 关于西红精算：品牌定位、四大内容支柱、关联项目、公众号与知识星球入口 |

## 数据时点

来源：美联储 FOMC、美国 BEA/BLS、国家统计局、中国人民银行、中债登、世界黄金协会、各公司财报。所有数字在页面内标注来源与日期；估算值均已注明。

## 技术说明

- `css/style.css`：设计系统（宣纸底 #f7f3e8 + 墨色 + 四季五色：春 #4a7c59 / 夏 #b53d2e / 秋 #bb8a1f / 冬 #3f5f7a）
- `js/charts.js`：无依赖 Canvas 图表库（折线/柱状/象限时钟/区间底色/注释）
- `js/ui.js`：移动端导航辅助
- `assets/`：品牌资产（公众号二维码 qrcode-gzh.jpg、Logo logo-xihong.png）
- 本地预览：`python -m http.server 8899` 后访问 `http://127.0.0.1:8899/index.html`；或直接双击 `index.html`（file:// 下同样可用）
- 打印：各页含 `@media print` 样式，可直接导出 PDF

## 更新流程（每季度约 2 小时）

1. 按 `refs.html` §6.3 数据源更新定位器 7 参数
2. 复盘上次判断（最重要）
3. 检查 `allocation.html` 的 5 个证伪条件
4. 执行再平衡（阈值 ±5pp）
5. 把新数据写回对应页面表格
