第一部分单选题（每题 2 分，共 40 分）

单选 1保险资金运用的首要原则是（　）。2 分
  • A. 收益性
  • B. 安全性
  • C. 流动性
  • D. 分散性
看答案

B。安全性第一（《保险法》106 条）。

单选 2若债券 YTM 高于票面利率，该债券（　）。2 分
  • A. 溢价发行
  • B. 折价发行
  • C. 平价发行
  • D. 无法判断
看答案

B。y > c → 折价。

单选 3零息债券的麦考利久期等于（　）。2 分
  • A. 0
  • B. 到期期限
  • C. 到期期限/2
  • D. (1+y)/y
看答案

B。零息债只有一笔现金流，加权平均时间 = 到期期限。

单选 4看涨-看跌平价关系（欧式、无股利）是（　）。2 分
  • A. C − P = S − K
  • B. C + P = S + K
  • C. C − P = S − K·e−rT
  • D. C + PV(K) = P + S
看答案

C。（D 也是对的，等价表述；但 C 是标准式）

单选 5下列风险测度中满足一致性风险测度全部公理的是（　）。2 分
  • A. VaR
  • B. 方差
  • C. CVaR（ES）
  • D. 标准差
看答案

C。CVaR 满足次可加性；VaR 不满足。

单选 6CPPI 策略中，风险资产投资额 =（　）。2 分
  • A. 组合价值 × 乘数
  • B. 缓冲垫 × 乘数
  • C. 保本额 × 乘数
  • D. 组合价值 − 保本额
看答案

B。E = m × Cushion（缓冲垫 × 乘数）。

单选 7Sharpe 比率与 Treynor 比率的区别在于分母分别是（　）。2 分
  • A. σ 与 β
  • B. β 与 σ
  • C. 跟踪误差与 σ
  • D. β 与跟踪误差
看答案

A。Sharpe 用 σ（总风险），Treynor 用 β（系统风险）。

单选 8Brinson 归因中，「配置贡献」的计算用（　）。2 分
  • A. 基准收益 × 权重偏离
  • B. 组合收益 × 权重偏离
  • C. 基准权重 × 类内超额
  • D. 组合权重 × 类内超额
看答案

A。配置贡献 = Σ(wp−wB)×RB。

单选 9根据流动性偏好理论，远期利率与预期未来即期利率的关系是（　）。2 分
  • A. f = E(s)
  • B. f > E(s)
  • C. f < E(s)
  • D. 无关
看答案

B。流动性偏好：f = E(s) + 流动性溢价 > E(s)。

单选 10虚值看涨期权（未到期）的价值构成是（　）。2 分
  • A. 内在价值 > 0，时间价值 = 0
  • B. 内在价值 = 0，时间价值 > 0
  • C. 内在价值 = 0，时间价值 = 0
  • D. 内在价值 > 0，时间价值 > 0
看答案

B。虚值无内在价值，但到期前有时间价值。

单选 11保险公司不能直接投资（　）。2 分
  • A. 国债
  • B. 银行存款
  • C. 对一般企业直接放贷
  • D. 金融债券
看答案

C。险资不能直接对企业放贷。

单选 12久期六法则中，票面利率越高，久期（　）。2 分
  • A. 越长
  • B. 越短
  • C. 不变
  • D. 先长后短
看答案

B。票息高，现金流靠前，久期短。

单选 13市场有效性中，能利用历史价格信息获取超额收益的情形属于（　）。2 分
  • A. 弱式有效
  • B. 半强式有效
  • C. 强式有效
  • D. 无效
看答案

D。若能利用历史价格（技术分析）获取超额收益，说明弱式有效都不成立，即市场无效。

单选 14Roy's Safety-First 准则中，最优组合是（　）。2 分
  • A. 夏普比率最大
  • B. SFRatio 最大
  • C. 期望收益最大
  • D. 方差最小
看答案

B。RSF 选 SFRatio = (E−RL)/σ 最大者。

单选 15我国保险公司权益类资产投资比例上限（一般情形）为（　）。2 分

单选 16两资产 ρ = −1 时，使组合标准差为零的权重应（　）。2 分
  • A. 等权 50/50

B。w₁ = σ₂/(σ₁+σ₂)，权重与 σ 成反比。

单选 17保险资金境外投资比例上限为（　）。2 分

单选 18关于久期与凸度，下列说法正确的是（　）。2 分
  • A. 凸度使债券在任何利率变动下都「涨多跌少」

第二部分简答题（每题 8 分，共 24 分）

简答 21简述相对估值法（P/E、P/B 等）的优缺点，并说明保险公司为什么优先用 P/B。8 分
看答案

优点：简单快速、反映市场当下定价、便于横向比较。

缺点：可比公司难找、无法识别系统性高估、对会计口径敏感。

险资优先 P/B：①资产即业务（净资产对应生息能力）；②盈利受准备金/拨备波动大（P/E 分母不稳）；③监管以资本为核心（P/B 与偿付能力逻辑一致）。

简答 22简述 CPPI 与恒定组合策略在支付曲线形状、操作方向、适用市场上的区别。8 分
看答案

CPPI：凸型支付，顺势操作（涨买跌卖），适合趋势市（下跌止损、上涨加仓）。

恒定组合：凹型支付，反向操作（涨卖跌买），适合震荡市（高抛低吸）。

方向相反的核心：CPPI 是「跌了卖」保底，恒定组合是「跌了买」抄底。

简答 23简述「风险中性定价」的含义，并说明为什么期权价格与标的真实期望收益率 μ 无关。8 分
看答案

含义：风险中性定价是「复制 + 无套利」的数学等价技巧，不假设任何人风险中性。

为何 μ 无关：期权可被「标的 + 无风险资产」精确复制，复制组合的价值与风险偏好无关，故定价只需 S₀、K、r、σ、T，μ 从公式中消失。

第三部分计算题（每题 12 分，共 36 分）

计算 24面值 100、票面利率 6%、年付一次、剩余 3 年、YTM=8% 的债券，求：①债券价格；②麦考利久期；③修正久期；④若利率上升 20BP，用久期估算价格变动。12 分
看答案

①P₀ = 6/1.08 + 6/1.08² + 106/1.08³ = 5.556 + 5.144 + 84.152 = 94.852

②DMac = (1×5.556+2×5.144+3×84.152)/94.852 = 268.30/94.852 = 2.829

③D* = 2.829/1.08 = 2.619

④ΔP/P ≈ −2.619×0.002 = −0.524%；ΔP ≈ 94.852×(−0.524%) = −0.497

评分：① 2 分、② 4 分、③ 3 分、④ 3 分。

计算 25标的现价 50，两期二叉树 u=1.2、d=0.8，单期无风险利率 6%，执行价 55。求：①欧式看涨期权价值；②初始对冲比率 Δ；③欧式看跌期权价值并验证平价。12 分
看答案

①p = (1.06−0.8)/(1.2−0.8) = 0.65；标的树 50→60/40→72/48/32

Cuu=17、Cud=0、Cdd=0；Cu=0.65×17/1.06=10.425；Cd=0；C₀=0.65×10.425/1.06=6.393

②Δ = (10.425−0)/(60−40) = 0.521

③Puu=0、Pud=7、Pdd=23；Pu=0.35×7/1.06=2.311；Pd=(0.65×7+0.35×23)/1.06=12.594；P₀=(0.65×2.311+0.35×12.594)/1.06=5.578

验证：C−P=0.815；S−K/(1.06)²=50−48.944=1.056（因 p 用单利离散，允许小幅误差）

计算 26某寿险公司资产 1000 亿（久期 8）、负债 900 亿（久期 12）。若利率下行 20BP，求：①资产、负债、净资产各自变动；②判断该公司面临什么利率风险。12 分
看答案

①ΔA = −8×1000×(−0.002) = +16 亿；ΔL = −12×900×(−0.002) = +21.6 亿；ΔE = 16−21.6 = −5.6 亿

②负债久期 > 资产久期（负缺口，k·DL=10.8 > 8），利率下行净资产受损，面临利差损/资产负债错配风险。

评分：ΔA 3 分、ΔL 3 分、ΔE 3 分、风险判断 3 分。

第四部分进阶挑战题（难度 ★★★★★，对标博迪原题与真题压轴，不计入 100 分）

挑战 A或有免疫：某基金当前组合价值 5000 万元，现行市场利率 8%，剩余期限 3 年。若立即免疫，3 年后可得 6299 万元；但基金经理要求「最终价值不低于 5500 万元」。①求触发点；②求安全垫；③若 1 年后组合价值跌至 4600 万元、市场利率升至 9%，判断此时是否已触发免疫，并说明后续操作。15 分
看答案与解析

① 触发点（初始） = 5500万/(1.08)³ = 5500/1.2597 = 4366 万元

② 安全垫 = 5000 − 4366 = 634 万元

③ 1 年后重新评估：剩余期限 2 年、利率 9%，新的触发点 = 5500万/(1.09)² = 5500/1.1881 = 4629 万元。

当前组合价值 4600 万 < 新触发点 4629 万 → 已触发，应立即转为免疫（锁定 9% 复利，确保 2 年后拿到 5500 万）。

关键：触发点随「利率上升」而上移。利率从 8% 升到 9%，触发点从 4366 万上移到 4629 万，安全垫被「利率上升」和「组合亏损」双重挤压，最终击穿。这正说明或有免疫的下行保护不是静态的，需要动态盯市。
挑战 BTreynor-Black：某经理被动市场组合 E(rM)=12%、σM=20%、rf=3%。他看好的股票 A 有 αA=2%、σ(eA)=15%、βA=1.2；股票 B 有 αB=1.5%、σ(eB)=10%、βB=0.8。①比较两股票的评估比率；②若只选一只，选哪只？为什么？10 分
看答案与解析

① 评估比率 = α / σ²(e)

A：0.02 / (0.15)² = 0.02/0.0225 = 0.889

B：0.015 / (0.10)² = 0.015/0.01 = 1.500

② 选 B。虽然 A 的 α（2%）更高，但 B 的「单位非系统风险的 α」（评估比率）更大——α 的质量（确定性）比 α 的大小更重要。这正是 Treynor-Black 的精髓：不是谁的 α 大，而是谁的 α 更「值钱」。

延伸：若 A、B 都纳入主动组合，权重应 ∝ 各自的评估比率（B 权重约为 A 的 1.69 倍）。
