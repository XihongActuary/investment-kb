T6.1投资决策的通用五步法

拿到任何资产，先问五句
现金流贴现率风险组合归因
▼五 步 决 策 链
①起点

现金流是多少？

债券=票息+本金；股票=股利/FCFE/RI；期权=max(S−K,0)
②核心

用什么贴现？

即期利率 / YTM / CAPM 的 re / 无风险利率
③—

风险从哪来？

利率（久期）、波动（希腊）、尾部（VaR/CVaR）
④—

怎么放进组合？

SAA 基准、相关性、分散化、保本
▼闭环：归因反馈
⑤反馈

赚的是哪部分钱？

配置贡献 / 选择贡献 / β / 运气
⑥检查

过了监管关吗？

比例、集中度、偿付能力、流动性
记忆：「先数钱、再折现、看风险、进组合、查归因、过监管」——六句话，覆盖全库。

T6.5归因工具箱（为什么赚/亏）

总超额 = 配置贡献 + 选择贡献 + 交互项
配置贡献 = Σ(wp−wB)RB　选择贡献 = ΣwB(Rp−RB)

四大比率：Sharpe（σ）、Treynor（β）、Jensen α、信息比率（跟踪误差）
一句话：「赚了钱先别高兴，用 Brinson 拆开看是配置赚的还是选券赚的，再用风险比率看值不值。」详见 T.04。

T6.6险资决策检查清单

任何一笔险资投资，落地前过一遍这份清单（可直接打印贴在工位）。

#检查项通过标准
1安全性资产符合《保险法》106 条及可投范围
2收益性预期收益 ≥ 负债成本 + 费用（利差为正）
3比例合规不超大类比例与集中度上限
4偿付能力资本占用在预算内，充足率不跌破底线
5久期匹配不扩大久期缺口（或已对冲）
6流动性匹配负债的现金需求，流动性匹配率 ≥ 100%
7会计影响明确 FVTPL/FVOCI/AC 分类对利润波动的影响

T6.7三类常见决策的应对模板

场景一

「要不要加仓权益？」

看决策模板

五步：① 看 ERP（盈利收益率 − 国债收益率）分位；② 看经济周期（美林时钟，复苏期加、滞胀期减）；③ 看偿付能力空间（资本够不够）；④ 看比例上限（是否已接近 30%）；⑤ 看波动对利润的影响（FVTPL 占比）。五步都过关，才加仓。

场景二

「利率下行期，债券怎么配？」

看决策模板

三步：① 抢久期（拉长资产久期锁定高利率）；② 对冲负债（久期缺口 → 利率互换/超长债）；③ 优化结构（骑乘策略赚期限溢价）。核心是「锁得早、对得好」。

场景三

「怎么判断一个投资经理是真本事还是运气？」

看决策模板

三步：① 用 Sharpe/Treynor/α 看风险调整收益；② 用 Brinson 归因看超额来源（配置 vs 选择）；③ 看跨周期、扣除费用后的可持续性。单一年份的高收益，概率上很可能是运气。
