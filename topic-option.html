期权与希腊字母

期权的价值来自「不对称」——涨了赚、跌了有限。希腊字母，就是解剖这种不对称的五个切面

T3.1期权定价三法回顾

① 二叉树：p = (1+r−d)/(u−d)，倒推 C₀ = [pCu+(1−p)Cd]/(1+r)
② Black-Scholes：C₀ = S₀N(d₁) − Ke−rTN(d₂)
③ 看涨看跌平价：C − P = S₀ − Ke−rT（欧式，无股利）

三法统一于「无套利 + 复制」：二叉树是离散版的 B-S，平价关系是两者的「公理」。
平价关系只对欧式成立。美式期权因可提前行权，只有不等式：S₀ − K ≤ C − P ≤ S₀ − Ke−rT。这是经典选择题考点。

T3.2希腊字母的完整体系

期权价格全微分（理解希腊字母的唯一正确方式）：
dC = Δ·dS + ½Γ·(dS)² + V·dσ + Θ·dt + ρ·dr
每一项 = 一种风险 × 对那种风险的敞口。管好希腊字母 = 管好期权组合的风险。
希腊字母定义看涨看跌含义
Delta Δ∂C/∂S0~1−1~0标的敏感度，对冲比率
Gamma Γ∂²C/∂S²>0>0Δ 的变化速度，平值最大
Vega V∂C/∂σ>0>0波动率敏感度，多头=做多波动
Theta Θ∂C/∂t<0<0时间衰减，多头付 Θ
Rho ρ∂C/∂r>0<0利率敏感度，长期期权才重要
口诀：「Delta 管方向、Gamma 管转弯、Vega 管恐慌、Theta 管时光、Rho 管利息」
救命四句：① 平值 Γ、V、Θ 最大；② 临近到期 Γ 最大、V 最小；③ 多头 Θ 负、Γ 正、V 正；④ ΔC − ΔP = 1。

T3.3动态对冲：Delta 中性及其缺陷

期权的核心应用是「对冲」。Delta 中性是最基础的对冲，但它有致命的缺陷——需要频繁调仓，且对 Gamma 与 Vega 敞口无能为力。

Delta 对冲：卖 1 份看涨，需买 N(d₁) 份标的，使组合 Δ = 0

Delta-Gamma 对冲：再用另一期权消除 Γ 敞口，减少调仓频率

Delta-Vega 对冲：再用另一期权消除 V 敞口，对冲波动率风险
Delta 中性的三个局限：① 需连续调仓（实际离散，有对冲误差）；② 只对冲了一阶（Γ、V 敞口仍在）；③ 假设波动率不变（实际 σ 随机，Vega 风险暴露）。这就是为什么期权对冲不是「一劳永逸」，而是「持续管理」。

T3.4四大期权策略

策略构成盈利条件风险/收益特征
保护性看跌股票 + 看跌期权下跌有保底，上涨不封顶成本 = 期权费；有限下行 + 无限上行
备兑看涨股票 + 卖出看涨横盘/小涨（赚期权费）上涨封顶、下跌无保护；增强收益
跨式/宽跨式买看涨 + 买看跌（同/不同执行价）大幅波动（无论方向）做多波动率；最大损失 = 期权费
蝶式/价差多腿组合小幅波动/区间做空波动率；收益有限、风险有限
一句话判断：「买期权 = 做多波动（付 Θ、收 Γ/V），卖期权 = 做空波动（收 Θ、付 Γ/V）。」看清自己站在波动率的哪一边，是期权交易的第一课。

T3.5险资的期权应用

应用一 · 保本产品（保护性看跌 / 合成保本）：分红险、投连险的保本，本质是「股票 + 看跌期权」或「债券 + 看涨期权」。用 B-S 框架可精确算出「保本的成本」，即期权费（见 CH.04 §4.6 变额年金）。

应用二 · 对冲利率与汇率风险：买利率上限/下限对冲浮动收益，买汇率期权对冲境外投资敞口（2023 年考「外汇对冲策略」）。

应用三 · 收益增强（备兑看涨）：在长期持有的股票上卖出虚值看涨，赚期权费增厚收益，但代价是上涨封顶——适合「预期横盘」的蓝筹组合。

应用四 · 波动率管理：隐含波动率偏高时卖期权（收 V 溢价），偏低时买期权（保护）——这是「波动率择时」的险资版本。

外汇风险的对冲：一段时间后会收到一笔欧元，对冲策略是什么？

看答案要点

情景：未来「收到欧元」（欧元多头敞口），担心欧元贬值。

对冲策略：卖出欧元期货/远期，或买入欧元看跌期权（锁定最低汇率，保留欧元升值的收益）。

易错：方向反了。「收到欧元」应卖出欧元（做空欧元对冲），不是买入欧元。

T3.7自测

单选1. 关于希腊字母，下列说法不正确的是（　）。2 分
  • A. 平值期权的 Gamma 最大
  • B. 到期日临近时 Vega 减小
  • C. 期权多头的 Theta 为正
  • D. 看跌期权的 Delta 为负
看答案与解析

答案：C。

期权多头（持有期权）的 Theta 为负（时间价值每天衰减，多头付 Θ）。A、B、D 均正确。

单选2. 某公司未来将收到一笔欧元，为对冲欧元贬值风险，应（　）。2 分
  • A. 买入欧元看涨期权
  • B. 买入欧元看跌期权
  • C. 买入欧元期货
  • D. 卖出欧元看跌期权
看答案与解析

答案：B。

收到欧元 = 欧元多头敞口，担心欧元贬值 → 买入欧元看跌期权（锁定最低汇率，保留升值收益），或卖出欧元期货/远期。

计算3. S₀=100、K=100、T=1、r=5%、σ=20%，求欧式看涨期权价值与看跌期权价值（用 B-S）。8 分
看答案与解析

d₁ = [ln(1)+(0.05+0.02)/1]/(0.2×1) = (0+0.07)/0.2 = 0.35；d₂ = 0.35 − 0.2 = 0.15

N(0.35) ≈ 0.6368；N(0.15) ≈ 0.5596

C = 100×0.6368 − 100×e−0.05×0.5596 = 63.68 − 95.12×0.5596 = 63.68 − 53.23 = 10.45

P = 100×e−0.05×N(−0.15) − 100×N(−0.35) = 95.12×0.4404 − 100×0.3632 = 41.89 − 36.32 = 5.57

验证平价：C−P = 4.88；S−Ke−rT = 100−95.12 = 4.88 ✓
