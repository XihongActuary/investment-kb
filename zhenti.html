2012大题 42（重点）

马先生 62 岁，出售公司得 5000 万元，不想组合失去 2% 以上价值，明年开销 100 万，3% 通胀，33% 税率。四种资产配置组合（国内股票 50/40/20/30、国外股票 25/20/10/0、公司债 10/20/30/35、现金 5/10/20/10、不动产 0/5/10/10、国债 10/5/10/15；夏普 0.46/0.6/0.75/0.88；税后收益 8%/7.2%/6.3%/5.2%）。国库券利率 2%。①计算四种组合 RSF = (E−最小可接受收益)/σ；②哪种最适合马先生。

看解题框架
核心：Roy's Safety-First（RSF）——「收益跌破最低可接受值的概率最小」的组合最优。

（1）最小可接受收益 RL 的确定

马先生「不想失去 2% 以上价值」→ 最低可接受收益 RL = −2%。（注意：RSF 的 RL 是「可接受的最低收益」，可为负——即「最多亏 2%」。）

（2）RSF = (E − RL) / σ，代入四个组合：

组合税后 E夏普 = (E−2%)/σ反推 σRSF = (E−(−2%))/σ
A8%0.46(8%−2%)/0.46 = 13.0%(8%+2%)/13% = 0.77
B7.2%0.60(7.2%−2%)/0.60 = 8.7%(7.2%+2%)/8.7% = 1.06
C6.3%0.75(6.3%−2%)/0.75 = 5.7%(6.3%+2%)/5.7% = 1.46
D5.2%0.88(5.2%−2%)/0.88 = 3.6%(5.2%+2%)/3.6% = 1.98

（3）结论：RSF 最大的是组合 D（1.98），最适合马先生——因为它「收益跌破 −2%」的概率最小（距离 −2% 有 1.98 个标准差）。

关键洞察：本题是「夏普比率最高 ≠ 最适合」的经典反例。组合 D 夏普 0.88 最高，但如果用「夏普最高」作为标准会选 D；而 RSF 标准下恰好也选 D——这里两者一致。真正的区分点在于：RSF 关注的是「跌破某一下限」的概率（保本），夏普关注的是「单位总风险的超额收益」。当投资者有「明确的最低收益要求」时，RSF 才是正确准则。
跨章关联：RSF 是「保本目标下的最优准则」，与 CPPI/OBPI（CH.05 §5.5）共同构成「下行保护」的工具箱。
